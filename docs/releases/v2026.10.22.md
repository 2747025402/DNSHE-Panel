# v2026.10.22 · 注册同步与自动续期工作页

本版本继续沿用仓库真实 React 前端与 Worker／Docker 后端，不新增数据库迁移，也不携带任何生产账号、Cookie 或 Token。公开体验仍使用 GitHub Pages 合成数据演示。

## 用户可见更新

- 新增“自动续期”独立工作页，支持设计风、数据风和卡片风三种平级阅读方式。
- 自动续期页集中展示续期阈值、策略开关、到期窗口、最近任务和单域名立即续期入口；缺少到期日期的域名保持未知并禁用续期动作。
- 注册成功后的域名列表同步增加有界重试和前端短暂轮询；仍未出现时明确显示待同步，不把旧列表当成新结果。

## 后端修复

- 自动续期候选包含已进入阈值的域名和已过期域名；无法解析到期日期的记录不会被猜测处理。
- 续期成功但上游没有返回 `new_expires_at` 时，保留数据库中的旧日期并记录 `renewal_result_incomplete`，不再写入空值。
- 注册后的缓存写入只补齐新域名，不覆盖同账号其它域名的 DNS 状态；后台重试仍受边界约束。

## 累计修复

- 注册目标账号直接显示已用／剩余配额，已用尽账号不可选；未知和读取失败不误判为用尽。
- 一键委派使用所选 Cloudflare 绑定的真实 Account ID；源记录快照未确认、Zone 归属不符或不唯一时中止，不再把面板本地主键当成供应商账号标识。
