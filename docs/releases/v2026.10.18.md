# v2026.10.18 · 三画风静态演示与自建版修复

本版本将真实前端界面与后端运行隔离：公开 Pages 直接构建仓库的 `frontend/src`，只替换 API 响应为合成数据；真实部署仍按使用者自己的 Worker、D1、KV 或 Docker 配置运行。

## 公开演示

- GitHub Pages：<https://shiranzby.github.io/DNSHE-Panel/>
- 设计风：以对象、结论和下一步为主，保留清晰的主辅轨道。
- 数据风：以范围、异常、比较和行级动作为主，使用共同列线。
- 卡片风：以自适应对象卡和快速浏览为主。
- 演示使用真实 React 组件和 CSS，但由 `VITE_STATIC_DEMO=1` 拦截 API，不读取 Cookie、Token 或本地文件，也不会修改任何真实资源。

## 工程更新

- Docker 自建版新增 SQLite-backed local KV，自动提供 `ASSIST_KV`，助力缓存随 `/data` 持久化。
- Cloudflare Workers 仍使用用户在 `wrangler.toml` 中配置的 `ASSIST_KV` namespace。
- 新增本地 KV 回归：`npm run test:local-kv`。
- Node 自建构建与验证：`npm run build:node`、`npm run verify:node`。

## 使用边界

- Pages 是前端展示，不代表后端 API 已配置，也不携带任何生产数据。
- 自建部署需要先复制 `.env.example`，按自己的账号创建 D1/KV 并注入密钥。
- 运行中的业务数据、登录会话和外部凭据不会随静态演示发布。
