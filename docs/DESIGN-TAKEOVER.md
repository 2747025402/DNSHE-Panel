## A. 资产页：一套列线，不是缩小卡片

场景：在多账号域名中定位一个对象，判断状态与到期风险，直接进入 DNS 操作。
历史快照的“账号框 → DNS 分组 → 域名框 → 元数据 → 操作底栏”重复分隔与内边距，应合并为一个列表工作面。

```text
页面身份／搜索                              同步（唯一 Filled）
账号筛选  DNS 类型  排序                  导出／展开收起（次级）
账号组标题 · 总数 · 同步时间／错误                       收起
资产／状态            注册／到期          DNS／来源        操作
DNS 类型小节（需要时，跨全宽；不再包一层卡）
域名 + 状态           两项有标签日期      服务商／来源     DNS  更多
域名 + 状态           两项有标签日期      服务商／来源     DNS  更多
```

| 轨道 | 桌面内容预算 | 规则 |
| --- | --- | --- |
| 资产／状态 | 弹性主列，优先获得剩余宽度 | 域名为可复制／可打开的稳定身份；长域名允许换行，状态有文字，不截成不可辨认的片段 |
| 注册／到期 | 同一固定轨道，数字等宽 | 明确标签；“永久”“未知”不是空白或零日期；CF 创建时间与注册商到期时间不得混写 |
| DNS／来源 | 弹性次列，有明确最小预算 | 已委派、未解析、系统默认等语义保留；长 NS 可完整查看，不以省略遮住唯一依据 |
| 操作 | 固定尾轨，所有行右缘一致 | 高频 DNS 直达；控制台／传播／删除等既有入口保留。危险操作仍确认；行内动作不误触整行 |

- 表头、每行、分组小节必须共用同一轨道定义；不要给每张卡单独算宽度或用 `justify-between` 假装齐列。
- 账号组保留折叠与计数；组间用一次分隔。需要吸顶时跟随主滚动面，不新增双层纵向滚动。
- 沿用现有 40px 表单规格；命中区不缩水。可见按钮较小时扩展不重叠的命中范围，移动端按 44px 预算。
- 窄窗依容器宽度重排：第一行“域名＋状态”，第二行“日期与 DNS”，末尾保留操作；字段不因隐藏表头而丢标签。
- 原有显式列数偏好只作用于其原有卡片视图；不能将其静默改为表格列数，也不能让用户选择后无视觉反应。
- 只允许可点击的行出现行级 hover；纯信息区不伪装为按钮。切换筛选／账号后保留已有状态规则，不重置用户偏好。

## B. CF 免费额度「设计」：结论带＋趋势证据

场景：快速理解当前余量和最近一次变化，能追溯到具体日期、账户与资源。

```text
设计／监控    账号范围                  数据截至／采集时间  刷新
一句可证实的结论（普通页面标题量级，不是大 Hero）
最高风险资源 · 适用范围 · 数据完整度
四项资源摘要，共用一条数值轨道；不再逐项包独立大卡
趋势（主区 3）                          峰值解释（辅区 2）
日期／单位／范围／阈值                  日期、贡献账户、比较口径
账户比较表（与监控复用数据语义，不复制第二套计算）
```

- 结论必须由可见证据支撑；部分账户失败时不能写“整体正常／余量充足”，应明确“部分数据不可用”。
- 多账户范围显示绝对用量与有效覆盖数，额度注明“每账号”而不与总量组成分数；单账号范围才展示该账号的百分比。账户间额度不可互借。
- 风险判断保留“单账号最高使用率”；合计仍有余量不代表每个账号安全。请求、行读写、存储分别保留单位与计费／统计周期。
- “数据截至日期”与“最近采集时间”分开；未结束日、缓存、权限不足、缺失日期均可辨认，不能把缺失画成真实零值。
- 趋势纵轴按真实值留有限余量，不为填满容器放大图；阈值线、图例、tooltip 与选中账号范围一致。
- 峰值说明只保留日期、值、账户贡献和可核验比较基准。若显示“相对其余日均值”，明确排除峰值日及缺失日；不可暗示已定位业务原因。
- 窄窗按“结论 → 摘要 → 趋势 → 解释 → 账户”单列，辅区不靠巨大 `min-height` 与图强行等高。

## C. CF 免费额度「监控」：异常在前，账户为行

场景：查找超阈值、同步失败或权限不全的账户，判断下一步，不先读一张占据半屏的大图。

```text
范围／更新时间／刷新
异常带：需关注 N · 请求失败 N · 权限不足 N · 缓存 N（按真实状态）
搜索账户  原有排序  仅看异常                           当前范围数量
账户／状态 | Workers | D1 读 | D1 写 | 存储 | 最高使用率 | 权限／更新时间
账户一行；数值带单位，可用小条形辅助，颜色只表达状态
展开所选账户：具体资源、失败原因、原有可用入口
趋势：按需查看或置于账户表之后，不挤走主要比较区域
```

- 异常带是筛查入口与状态汇总，不是第二套统计卡墙；无异常时用一条短状态即可。
- 表头与数值右对齐；账户身份左对齐。总量、使用率和阈值不能仅凭颜色区分，失败状态在原单元格保留原因或详情入口。
- `0` 只表示真实零；`—／不可用／权限不足／读取失败` 各有准确语义。旧缓存保留时间标签，不伪装为本次成功。
- 展开、排序、过滤共用稳定账户 ID；展开不会隐式刷新或写数据。切换设计／监控不丢范围，也不另发重复读取。
- 手机优先显示身份、最高风险、权限／采集状态及展开入口；其它指标在详情完整保留。若保留二维表，横滚限表内且有提示。
- 本稿不新增告警系统、阈值配置、趋势数据源或后台轮询；没有现成接口的入口不得画成已可用功能。

## 12 页结构优先级

P0／P1／P2 表示结构改造顺序，不表示已实施状态或安全缺陷严重度。

| 优先级 | 页面 | 结构目标与保留边界 |
| --- | --- | --- |
| P0 | 域名列表 | 按 A 收敛共享列线；保留账号／DNS 分组、筛选、排序、委派及 DNS 流程 |
| P0 | Cloudflare | 与域名资产页共享轨道与操作层级；保留 zone 身份、控制台深链、传播入口和权限提示 |
| P0 | CF 免费额度 | 按 B／C 区分两种阅读任务；统一范围、缺失语义、额度与趋势口径 |
| P1 | 概览 | 指标去重；配额与最近注册共用边缘；CF 摘要不成为宽屏左半边的孤岛；近期记录保留日期 |
| P1 | 账号管理 | CF／DNSHE 两组同列数、列宽、边缘与 gap；一个绑定主动作；编辑／删除为稳定次级操作 |
| P1 | 账户配额 | 每账户同一数值轨道：可用／已用／总额；去掉上下重复比例，保留隐藏账号与列数偏好 |
| P1 | API 密钥 | 保留既有表格和快照优先；密钥身份、状态、有效期、操作齐列；不改 Secret 解密与安全边界 |
| P1 | 运行日志 | 筛选与分页共带；时间／级别／对象／消息齐列；长错误可展开，不能只剩瞬逝通知 |
| P1 | 设置 | 按任务分组、状态先行、长说明按需；不新增二级侧栏，不用末卡拉伸制造大空白；保存／失败保稿不变 |
| P2 | 域名助力 | 额度、可操作域名、历史记录分工；保留账号排除、确认与消耗说明，不以图表挤走主操作 |
| P2 | 注册／查重 | 输入与运行控制在前，结果列表随后；暂停／继续／停止与断点语义不变，减少重复说明 |
| P2 | 动态 DNS | 任务行显示对象、目标、最近执行、状态与操作；密钥和执行失败按需详情，不增加假实时监控 |
